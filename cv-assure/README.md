# CV-Assure

Computer-vision assurance workspace organized into cross-cutting services and assurance modules M0-M6.

## Structure

- `shared/`: audit ledger, cryptography, and reference-profile primitives
- `m0_ingest_capability/`: ingest, normalization, and capability probing
- `m1_data_integrity/`: data-integrity checks
- `m2_model_integrity/`: model-integrity checks
- `m3_inference_provenance/`: inference provenance workflow
- `m4_distribution_shift/`: distribution-shift sentinel
- `m5_risk_fusion/`: evidence fusion and policy decisions
- `m6_assurance_report/`: reports and governance coverage
- `attack_simulation_harness/`: benchmark attack generation
- `benchmark/`: benchmark runner and results
- `docs/`: architecture and coverage documentation

Implementation files are scaffolded and ready to be filled in module by module.
